# Repository Instructions

## Language and Localization

- Communicate with the user in English only.
- Do not author or translate Korean UI copy unless the user explicitly requests it.
- Preserve the existing localization structure and keep locale files structurally aligned.
- When adding a new localization key, add the key to `cmLabels.ko.js` with the English text as a temporary fallback. Korean staff will provide the Korean translation later.
- Do not remove or rewrite existing Korean translations unless the task explicitly requires it.
